# TP - 02. API - Formulaire pour aller requêter une API distante

Application web permettant de récupérer, afficher, gérer et sauvegarder des blagues via JokeAPI.

## Fonctionnalités

- Récupération de blagues via requêtes HTTP.
- Affichage dynamique dans un tableau HTML.
- Suppression unitaire d'une ligne du tableau.
- Persistance des données dans le navigateur via `LocalStorage`.


## Choix techniques

- **HTML / JavaScript**
- **Tailwind CSS**
- **API Request :** `https://v2.jokeapi.dev/joke/Any?lang=fr&blacklistFlags=nsfw,religious,political,racist,sexist,explicit`
